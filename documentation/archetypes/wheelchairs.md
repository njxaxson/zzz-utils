# Wheelchairs

A "wheelchair" is a support pairing that uplifts almost any compatible carry — you can slot
nearly anyone into the third seat and get a good team.

## The current pairings

| Pairing | Carry type |
|----|----|
| Astra + Nicole | attack |
| Nangong + Yuzuha | anomaly |
| Vivian + Yuzuha | anomaly |
| Velina + Remielle | anomaly (the [triple-anomaly](triple-anomaly.md) track) |
| Nangong + Sunna | attack or anomaly (and sometimes even rupture, based on emergent mechanics) |
| Dialyn + Lucia | rupture |
| Norma + Astra | attack |
| Norma + Lucia | rupture |

This list is not exhaustive; powerful stunners and supports will naturally create a framework for interchangeable DPS agents to slot in as the third member to match enemy weakness. 

## Why this list matters

These pairings are **emergent**. The engine is not told that any of them are good; they score
highly because of the buffs and utility those units supply, evaluated one mechanic at a time.

So a high wheelchair score is evidence the mechanics are modelled well. If one of these
pairings stopped topping its ladder after a change, that is a signal something in the
mechanics broke — not a signal that a template needs updating.

The exception worth knowing about is the Remielle track, where the engine could not see
Velina's contribution and two relationships had to be declared. That story is on the
[triple-anomaly](triple-anomaly.md) page.
