# Monoshock

**Shape:** a hybrid anomaly and attack team.

The name comes from the old triple-electric Grace / Harumasa / Rina team, but it no longer
means that literally. Today it means any hybrid anomaly-plus-attack composition; it need not
be electric, and it need not be three of one element.

Niche but legal. What makes such a team score at all is a `scaling.anomaly` entry on an
attacker — Harumasa's is the example — which lets an attack carry cash in the team's anomaly
proc volume instead of ignoring it.

See [scaling](../data-model/scaling.md) for how that key is read.
